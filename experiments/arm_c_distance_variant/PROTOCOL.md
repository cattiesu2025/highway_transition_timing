# 新增 Arm C 距离变体：范围修正

状态：2026-10-26 按用户澄清修正。已实现独立 runner 与本地验证入口；未提交正式训练，原 A/B/C 未修改。本目录仅用于新增 Arm C 距离变体。

## 实验范围

用户要求新增实验只调整距离。保留现有 A/B/C 的配置、模型和结果；本任务不要求修改或重训原 A、B、C。新增独立的 C 距离变体（下称 C-distance），研究黄车比白车更远时的行为。原 C 继续作为原几何条件，新增结果单独报告。

上一版将任务扩大为统一 A/B/C 的公共采样、动作速度表和惩罚项并训练 180 个模型，超出了本次范围，现已废止。历史稿保存在 `archive/SUPERSEDED_UNIFIED_DRAFT.md`，不可据此生成任务。

## 只改距离的含义

- D_o 为 ego 到原车道白车的初始纵向中心距离。
- D_t 为 ego 到目标车道黄车的初始纵向中心距离。
- 新几何要求 D_t > D_o，且初始车辆可见；两者相对 ego 定义，不能只指定黄白车之间的距离。
- 白车 40–150 m、黄车 D_t=D_o+ΔD 且 ΔD 在 30–min(80,195−D_o) m 内，是已有 pilot 的候选几何，不是已冻结的正式参数。

以选定的原 C 基线为依据，继承速度设置、奖励系数、公共惩罚、动作及纵向目标速度表、算法、训练预算、场景类型配额、评估时长、端点与模型选择规则。ego 训练初速支持为 24–31 m/s，慢白车为 10–20 m/s，黄车固定 29 m/s；同速、非闭合等控制类型继承各自原定义。不采用 pilot 固定 ego 28 m/s 和 60/20/20 场景比例来替换原 C 训练协议。

此前确认的 FD/F1、BAL/F4、SP/F7 权重分别为 (speed, front spacing)=(0.28,1.12)、(0.56,0.84)、(0.98,0.42)，继续保留。距离对照应匹配 `experiments/reward_sensitivity/SELECTED_VALIDATION.md` 中同权重的 C 基线，先核实已有模型是否完成及配置是否相符；不能将采用旧权重的历史 C 直接称为“仅距离不同”的配对对照。已有匹配基线可以复用，不因新增距离实验而重训。若缺少匹配基线，应明确报告缺口，不扩大为重训 A/B/C。

## 距离与原联合采样的兼容性

原 C 将距离、闭合速度、TTC 和所需减速度联合采样。改变距离时，TTC 和所需减速度允许作为几何变化的结果改变；不能为了维持旧难度标签而偷偷改变速度分布或场景比例。

实现前应检查如何保留基线速度样本和类型配额，再生成新距离。特别是原“边界可见”白车距离 180–195 m 与候选 40–150 m 不兼容；候选距离尚不能直接套用。应在距离设计中解决并记录该矛盾，不静默删除场景类型，也不因此修改原 A/B/C。若最终必须改变距离以外的因素，应明确说明，不能仍称为纯距离变体。

同样继承原模型选择规则并记录不合格模型；不得为获得时间差而改 gate 或改选最终检查点。新几何下规则适用性可先检查，不能直接把 pilot 的 fixed-100k 选择替换进来。

## 训练与比较

只为新增 C-distance 分布训练独立模型，输出使用新前缀。若沿用 3 个权重 × 20 seeds，新增规模为 60 个模型的候选计划，不是 180 个 A/B/C 模型；本说明不代表已经授权或提交正式训练。

主要对照是同权重、同非距离设置的原 C 与 C-distance；A/B 保留已有结果作为背景，不声称它们与 C-distance 构成新统一采样实验。训练 seed 为独立重复。仅将旧 C 模型放到新距离评估，可作为泛化诊断，应与在新距离分布重训的结果区分。

## 已有 pilot 能说明什么

larger-gap v1 与 broad-v2 使用相同速度设置，扩大距离支持并重训后出现远距离延后换道。因此没有证据要求为了获得响应而修改速度。不过两轮几何支持和评估网格也不同，且使用旧奖励权重，仅有 3 seeds，不能当作新 F1/F4/F7 变体的正式结论。

## 当前开发实现（2026-10-26）

`run.py` 使用 `distance-affine-v1`：先生成原 C 场景，再把白车 90–195 m 线性映射为 40–150 m；将原黄车距离在 10–90 m 中的位置比例映射为额外距离 30–min(80,195−D_o) m。原场景的速度、存在性、随机 seed 和配额逐 reset 保持一致，TTC 与减速度随距离重新计算。此规则保留白车远近顺序，不声称新白车距离均匀分布，也不是照搬 broad-v2 的独立采样。

这解决了上述边界类型的实现问题：保留其来源与速度样本，将原 180–195 m 映射为约 134.286–150 m；原类型名只表示来源，不能称新位置仍在观测边界。源难度标签单独记录。开发评估也对原 C 的 36 场景应用同一映射，保持速度及场景配对。完整公式、命令、控制干预语义和适用限制见 [README.md](README.md)。

当前实现可进行审计、短程 smoke 和单个独立训练任务；正式 20-seed 结果及新 held-out 均未产生。仅对新增变体开展后续开发，不修改或提交原 A/B/C 重训任务。
