# Pilot results — 2026-10-24

## Completion and integrity

本地收齐 9/9 个真实 pilot：5200–5202 × FD/BAL/SP。逐个检查模型 ZIP 内 `num_timesteps=100000`、complete 标记、protocol 与 source SHA256；记录的源码哈希均与当前对应文件一致。Smoke 未纳入。

每模型 4 variants × 27 scenes × 20 s，合计 972 episodes、97,200 个决策步。所有 episode 均完整记录 20 s，全部无碰撞。汇总文件：`outputs/larger_target_gap_pilot_summary/{job_status.csv,summary.csv,status.json}`。

## Main scene

| 条件 | 换道 / 总数 | 碰撞 | 首步向左换道指令 | 首次实际车道变化时间 |
|---|---|---|---|---|
| FD | 81 / 81 | 0 / 81 | 81 / 81 | 全部 0.6 s |
| BAL | 81 / 81 | 0 / 81 | 81 / 81 | 全部 0.6 s |
| SP | 81 / 81 | 0 / 81 | 81 / 81 | 全部 0.6 s |

逐步日志确认所有主场景 t=0 动作都是 LANE_LEFT。0.6 s 是 post-step 车道索引第一次变为目标车道的采样时间，不是策略等了 0.6 s 才决定换道，也不等同于完全居中。

243/243 次换道在首次指令前与物理端点前均满足目标车道前方净间距更大：

- 首次指令前：白车净间距 40–70 m，黄车净间距 75–145 m。
- 物理端点前的记录状态（0.4 s）：白车净间距约 32.74–65.94 m，黄车净间距约 75.34–145.34 m。
- 该状态下黄车方向多出约 39.4–82.6 m。

场景和行为符合“原车道前车较近，目标车道空间更大”的设定。但所有策略立即换道，观测到的是共同的早期响应，当前网格无法提供三种奖励条件的决策时间分离。

20 s 内，201/243 个主场景 episode 随后返回原车道；所有返回动作造成的车道索引变化之前，ego 都已超过白车。其余 42 个未返回。没有观察到多次来回跨线；不能把返回本身误报为首次换道失败。

## Paired controls

每格分母均为 81 episodes（3 seeds × 27 scenes）。时间是已观察到换道样本的描述均值。

| Variant | FD 换道数；平均时间 | BAL 换道数；平均时间 | SP 换道数；平均时间 |
|---|---|---|---|
| no-front | 0；不适用 | 0；不适用 | 0；不适用 |
| open-target-lane | 81；0.874 s | 81；0.763 s | 81；0.644 s |
| matched-speed-front | 81；0.874 s | 81；0.600 s | 81；0.607 s |

所有控制场景碰撞数为 0。no-front 的 243 次未换道为 20 s 内未观察到事件，不能将其换道时间写成 0。

移除白车后完全不换道，支持原车道前车的存在影响该行为；但将白车改为同速后仍全部换道，说明不能把本次结果单独解释为“只有慢前车造成速度阻碍才换道”。空间奖励可能参与驱动，仍需独立干预才可进一步确定机制。

移除黄车时部分 episode 反而换道更晚，不能据此断言空间更大导致更晚换道：训练中的三个场景类型始终保留黄车，因此空目标车道属于占用状态变化后的泛化评估。该控制与训练支持的差异应明确报告。

## Assessment

- Pilot 在运行、几何关系和无碰撞换道方面通过检查。
- 当前主网格所有策略在首步动作，存在决策时间的地板效应；不建议直接扩大到 20 seeds 来期待时间差异。
- 若下一步仍研究 timing，可在保持 D_t > D_o 的前提下，设计更宽的原车道距离和较温和闭合速度探测，以观察等待/减速/换道的边界；新的距离范围须同时核对目标车可见性与奖励饱和。
- 若研究重点是验证合理的换道场景，本 pilot 已提供开发期行为证据。若重点是三种奖励的时间差异，结果目前不支持该差异，但也不等于一般性的策略等效结论。
- 本报告仅描述 3 个独立训练 seeds 的开发 pilot，不作 episode 级伪重复显著性检验，不更改既有 A/B/C 或 held-out v2 结论。未启动额外训练。
